# Engineering & Coding Standards Specification

## 1. Протокол агента (Stop-Rule & Surgical Diffs)

1. **Stop-Rule:** При нехватке метаданных о схеме SQLite, портах или окружении генерация кода прекращается. Агент обязан выдать список read-only команд для сбора данных (`sqlite3 ... PRAGMA table_info`, `stat -c '%a %U:%G'`, `ss -tlpn`).
2. **Принцип минимального радиуса (Surgical Diffs):** Монолитные файлы не переписываются целиком; правки вносятся точечно с сохранением валидаторов и обработчиков исключений.

## 2. Стандарты Bash-разработки

- Интерпретатор: строго `#!/usr/bin/env bash`.
- Режим выполнения: строго `set -Eeuo pipefail` и `umask 077` в начале файла.
- Структура: Обязательное обрамление в функцию `main()` с финальным вызовом `main "$@"`.
- Ловушки сигналов (Traps):
  - Раздельные обработчики для `EXIT`, `ERR`, `INT`, `TERM`.
  - Перехват `INT` и `TERM` возвращает коды `130` и `143` соответственно.
  - Внутри ловушки `ERR` сбрасывается ловушка (`trap - ERR`) для предотвращения рекурсии.
- Безопасность путей:
  - Все переменные и подстановки строго экранируются: `"$var"`, `"$(cmd)"`.
  - Использование защитного разделителя `--` во всех файловых операциях (`rm -f -- "$file"`, `mv -f -- "$src" "$dst"`).
  - Запрет на размещение дампов и тяжелых файлов в `/tmp` и `/run` (tmpfs). Размещение строго внутри `${BACKUP_DIR}/.work`.

## 3. Стандарты разработки на Python (`xui_standby_sync`)

- Runtime: Только Python Standard Library (версия Python >= 3.10). Внешние зависимости запрещены.
- Разделение ответственности:
  - `planner.py`: Строго Read-Only (`mode=ro`). Формирует `SyncPlan`.
  - `engine.py`: Исполнитель. Применяет изменения в БД.
- SQLite:
  - Подключение с `isolation_level=None`.
  - Границы транзакций строго через `BEGIN IMMEDIATE TRANSACTION;` и `COMMIT;` / `ROLLBACK;`.
  - Имена колонок и таблиц проверяются регулярным выражением `^[A-Za-z0-9_]+$`. Параметры подставляются исключительно через `?`.
- Исключения: Запрещен слепой перехват `except Exception:`. Перехватываются конкретные `sqlite3.Error`, `OSError`, `json.JSONDecodeError`.
- Уничтожение секретов: Удаление дампов утилитой `shred -u -z -n 1`. Запрещено вызывать `os.remove()` после `shred`.

## 4. Разграничение привилегий

- Root-компоненты: `xui-backup`, `xui-restore`, `xui-standby-sync` (EUID == 0).
- Non-root компоненты: `xui-backup-receiver` строго под `xbackup` (EUID != 0).
- Права каталогов: Общесистемным каталогам (`/usr/local/bin`) запрещено присваивать права `0700` (строго `0755 root:root`).
