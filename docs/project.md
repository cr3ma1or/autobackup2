# Project Overview: Resilient Backup & Standby Sync Suite

## 1. Назначение системы

Автоматизированный комплекс резервного копирования, безопасной передачи данных и селективной транзакционной синхронизации пользовательской базы для панели управления трафиком 3x-ui (SQLite).

## 2. Архитектурная цель

Обеспечение отказоустойчивости схемы Hot-Standby:

- Постоянная непрерывная синхронизация учетных записей пользователей и правил маршрутизации с первичного узла (Primary) на резервный шлюз (Secondary).
- Исключение ручной миграции клиентских баз при выводе из строя или блокировке первичного узла.
- Сохранение клиентских учетных записей (UUID, ключи, сроки действия, лимиты) в консистентном состоянии.

## 3. Ключевые возможности

1. **Consistent Hot SQLite Dump:** Создание бинарных слепков SQLite через Online Backup API без остановки сервиса.
2. **Zero-Knowledge Transport:** Асимметричное шифрование архивов (GPG AES-256) для двух независимых открытых ключей и отправка потоком через SSH Forced Command.
3. **Host Identity Preservation:** Защита сетевых параметров и системных портов резервного хоста от затирания при репликации.
4. **Dual-Layer Synchronization:** Одновременная транзакционная модификация таблицы `clients` и JSON-конфигураций ядра `inbounds.settings`.
5. **Failover Automation:** Минимальное время переключения (RTO < 30 секунд) без изменения клиентских подписок.
